Send the task.

Oracle classifies the work, chooses an execution model, applies QA and failover when needed, and returns routing telemetry with the result.

API v1

POST /v1/oracle — authenticated execution endpoint.

curl -X POST https://oracle-stack.onrender.com/v1/oracle \
  -H "Authorization: Bearer YOUR_ORACLE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"request":"Design a reliable background-job API for my Node app."}'

The response includes the finished answer plus the selected specialist, execution model, QA status, latency, token usage, routing reason and failover telemetry.

Usage

GET /v1/usage returns the authenticated key's quota and usage totals. This makes it possible to meter customer access without exposing provider credentials.

curl https://oracle-stack.onrender.com/v1/usage \
  -H "Authorization: Bearer YOUR_ORACLE_KEY"
